# lab-web-5

**Student Management System** — современное веб-приложение на базе метафреймворка **AnalogJS** (для Angular) для управления записями студентов через внешний Java REST API. Проект представляет собой миграцию SPA-приложения из лабораторной работы №4 на архитектуру с поддержкой серверного рендеринга (SSR), файловой маршрутизации и кеширования данных.

## 📝 Лабораторная работа №5. Frontend на метафреймворке

Перенести frontend системы управления студентами из лабораторной работы №4 на метафреймворк в соответствии с ранее выбранной технологией:
* React — Next.js;
* Vue — Nuxt;
* Svelte — SvelteKit;
* Angular — AnalogJS.

**Приложение должно сохранить основную функциональность лабораторной работы №4:**
* авторизация и регистрация пользователей с использованием JWT;
* просмотр списка студентов;
* поиск, фильтрация, сортировка и пагинация;
* добавление, редактирование и удаление студентов;
* разграничение доступа по ролям;
* просмотр профиля пользователя.

**Дополнительно необходимо реализовать возможности метафреймворка:**
* серверный рендеринг (SSR);
* динамические маршруты, включая страницу студента `/students/[id]`;
* защиту маршрутов и перенаправление неавторизованных пользователей с помощью middleware;
* обработку состояний загрузки, ошибок и страницу 404;
* кеширование данных с обновлением после изменений.

**Требования:**
* Frontend должен взаимодействовать с Java-backend из лабораторной работы №3.
* Бизнес-логика, авторизация и работа с базой данных остаются на Java-backend.
* Серверные возможности метафреймворка используются только для реализации frontend-функциональности (SSR, маршрутизация, middleware и получение данных).
* Приложение должно сохранить адаптивность интерфейса.
* Приложение должно быть контейнеризировано с использованием Docker.

## Основные возможности

* **Авторизация и безопасность:** регистрация и аутентификация пользователей на базе JWT, защита маршрутов и перенаправление неавторизованных пользователей с помощью **Middleware**, разграничение прав доступа по ролям.
* **Управление студентами (CRUD):** просмотр общего списка, добавление, редактирование и удаление записей без полной перезагрузки интерфейса.
* **Динамическая маршрутизация:** детальная страница каждого студента по маршруту `/students/[id]`.
* **Работа со списками:** поиск, фильтрация, сортировка и пагинация данных.
* **Профиль пользователя:** просмотр информации о текущем авторизованном пользователе.

## Архитектурные особенности (AnalogJS)

* **Серверный рендеринг (SSR):** улучшение скорости первоначальной загрузки страниц и SEO-оптимизация при сохранении реактивности клиента (Hydration).
* **Файловая маршрутизация:** автоматическое построение роутинга и вложенных макетов (Layouts) на основе структуры директорий.
* **Кеширование и инвалидация данных:** оптимизация запросов к REST API с автоматическим обновлением кеша после создания, изменения или удаления записей.
* **Обработка состояний:** встроенная обработка состояний загрузки (Loading), перехват ошибок (Error) и кастомная страница `404 Not Found`.

## Технологический стек

* **Фреймворк / Метафреймворк:** Angular, AnalogJS (Vite, Nitro)
* **Реактивность и состояние:** RxJS, Angular Signals / NgRx

* **Стилизация:** адаптивная верстка (CSS / SCSS / Tailwind CSS)
* **Инфраструктура и деплой:** Docker, Docker Compose
